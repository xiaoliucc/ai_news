## 2. 功能清单（当前已具备）

**数据管道**：`models` / `sources/base` / `sources/{hackernews,arxiv,papers,rss,github,csdn}` / `engine`（并发+去重+排序+统计）/ `filters`（关键词，LLM 降级回退）/ `output`（text/json/markdown）/ `main`（click 命令组）/ `pipeline/{dedup,ranking,llm}`

**后端**：`config` / `database`（3 表 + WAL + 3 次列迁移）/ `scheduler`（APScheduler，`_filter_ai_related` 4 线程 + LLM 打分）/ `vector_store`（ChromaDB 惰性初始化）/ `main`（lifespan + CORS + 可选 API_TOKEN 中间件 + 静态托管）/ 5 个 router（articles/sources/stats/collect/agent）/ `agent/{core,tools,prompts,memory}`（6 工具、最多 5 轮、SSE 真流式）

**前端**：三栏 Dashboard（信息源开关 / 文章·趋势·热榜 / Agent 对话）、双主题、axios 层、4 个 Pinia store、SSE 增量读取、停止生成

**运维**：Docker 单容器全栈、GitHub Actions 日报、cpolar 双隧道、可选 API_TOKEN 门禁、`docs/功能验收清单.md` 一键体检

## 4. 已解决的技术议题

| 议题 | 结论 |
|---|---|
| 关键词过滤 vs LLM 语义判断 | LLM 优先、关键词兜底（降级链），非二选一 |
| 持久化 | SQLite（WAL）单文件，3 张表；个人量级足够 |
| 定时调度 | APScheduler 进程内调度，比系统 cron 易维护 |
| Agent 实现 | 手写 tool-use loop（非 LangChain），6 工具 / 5 轮 |
| 前端 mock → 真实数据 | 保留 UI 层，替换数据层（`src/api/` + store），设计稿零改动 |
| 对话流式 | 前后端一致做真流式（SSE），删除模拟器与工具标签猜测 |
| 国内数据源 | 官方 RSS（机器之心）+ GitHub 静态页 + CSDN JSON 接口；知乎/RSSHub 放弃 |
| 部署 | Docker 单容器（无云服务器）；将来迁服务器只需 compose |
| 公网暴露 | 可选 `API_TOKEN` 门禁，单用户语义不做多用户鉴权 |
